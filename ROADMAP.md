# Blog Studio Roadmap

## Phase 1：Arch-first native foundation

- [x] Tauri 2 desktop shell;
- [x] native local Markdown read/write;
- [x] Git status, diff and local commit;
- [x] explicit remote pull/push;
- [x] file picker image insertion;
- [x] clipboard and drag-and-drop image insertion;
- [x] visual editing MVP;
- [x] date/category/tag metadata editing;
- [x] Arch PKGBUILD draft;
- [x] Arch desktop entry;
- [x] Linux deb/rpm build;
- [x] public source repository.

## Phase 2：Editing quality

- [ ] full WYSIWYG editor with reliable Markdown round-trip;
- [ ] tables;
- [ ] links;
- [ ] task lists;
- [ ] strikethrough;
- [ ] undo/redo history;
- [ ] keyboard shortcuts;
- [ ] rich-text paste cleanup;
- [ ] image preview and delete management;
- [ ] broken asset detection;
- [ ] front matter validation;
- [ ] article preview using the exact blog renderer.

## Phase 3：GitHub authentication

- [ ] browser-based GitHub authorization;
- [ ] OS credential storage on Arch and Windows;
- [ ] repository picker;
- [ ] account/logout state;
- [ ] clear local credentials;
- [ ] friendly authentication errors;
- [ ] no token in source, logs or Markdown.

## Phase 4：Sync safety

- [ ] readable pull conflict screen;
- [ ] local changes protection;
- [ ] remote branch selection;
- [ ] push preview;
- [ ] files-to-upload summary;
- [ ] offline sync queue;
- [ ] retry after network recovery.

## Phase 5：Distribution

- [ ] Arch `blog-studio-git` AUR package;
- [ ] Arch install/uninstall test;
- [ ] Linux AppImage;
- [ ] Windows MSI/NSIS CI artifacts;
- [ ] GitHub Releases;
- [ ] signed release process;
- [ ] release notes automation.
